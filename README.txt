# GABRUZ — Free Website Starter

This is a static website for GABRUZ Collection.

## Features
- Mobile-friendly storefront
- Product catalogue
- Buy Now buttons
- WhatsApp ordering to +91 97817 53113
- Customer order form
- No paid e-commerce platform required

## Put it online for ₹0
1. Create a free GitHub account at github.com.
2. Create a new public repository named `gabruz`.
3. Upload `index.html`, `style.css`, and the `images` folder.
4. In the repository open Settings → Pages.
5. Select "Deploy from a branch", choose `main` and `/root`, then Save.
6. GitHub will give you a free `github.io` website address.

## Before accepting online payments
The current site sends the order to WhatsApp and asks you to confirm availability, delivery charges and payment. Add your UPI/payment details only after you decide how you want to handle refunds, returns and shipping.

## Editing
- Change prices/products in `index.html`.
- Replace product photos inside `images/`.
- Change WhatsApp number in the `wa.me` links and JavaScript if the business number changes.
